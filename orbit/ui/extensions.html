Extensions

An extension is a folder with a manifest.json and scripts/styles that Orbit injects into pages. Put your folders in the extensions folder and reload this page.

Example manifest.json

{
  "name": "Hide cookie banners",
  "version": "1.0",
  "description": "Hides annoying overlays",
  "matches": ["*://*.example.com/*"],
  "run_at": "document_end",
  "js": ["content.js"],
  "css": ["style.css"]
}
